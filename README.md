## 🚀 Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_ORG/ai-secure-analyzer.git
cd ai-secure-analyzer

# 2. Backend setup
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload

# 3. Frontend setup (separate terminal)
cd frontend
npm install
npm run dev
```
